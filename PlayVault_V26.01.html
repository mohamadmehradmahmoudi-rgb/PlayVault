درباره PlayVault

🔐 امنیت حساب

  • ورود و ثبت‌نام فقط از طریق Supabase Auth انجام می‌شود.
  • رمز عبور در localStorage ذخیره نمی‌شود.
  • اطلاعات نمایشی و تنظیمات محلی از اعتبارنامه‌های ورود جدا هستند.
  • سطح دسترسی مدیر باید از دیتابیس تأیید شود.

امنیت نهایی به اجرای فایل SQL همراه نسخه و فعال بودن سیاست‌های RLS در Supabase وابسته است. این فایل به‌تنهایی تنظیمات سرور را تغییر نمی‌دهد.

پشتیبان اطلاعات

برای جلوگیری از گم‌شدن اطلاعات در مرورگرهای موبایل، هر از گاهی از حساب، علاقه‌مندی‌ها و نظرها فایل پشتیبان بگیر و آن را در جای امن نگه دار.

نمونه اولیه یک سایت کشف، معرفی و هدایت به فروشگاه‌های بازی. اطلاعات و لینک‌های فروشگاهی در این نسخه نمایشی هستند؛ برای اتصال کتابخانه هزاران بازی، API و سرور لازم است. اگر پس از خاموش‌روشن شدن گوشی باز نشد، فایل را دوباره از Downloads با Chrome باز کن؛ پیش‌نمایش فایل ممکن است محدودیت داشته باشد. ذخیره‌سازی فایل‌های محلی در برخی گوشی‌ها پایدار نیست؛ برای حفظ اطلاعات از بخش پشتیبان استفاده کن.

دستگاه شما

🚀 PlayVault — Security & Core Rebuild

بازسازی مسیر ورود، حذف اعتبارنامه‌های محلی، تأیید نقش مدیر از دیتابیس، جست‌وجوی کاربران و صندوق ورودی پیام‌ها، و تکمیل کنترل‌های مالکیت پست‌های انجمن.

🔐 ورود امن‌تر

ورود و ثبت‌نام فقط با Supabase Auth؛ رمزهای قدیمی از داده‌های محلی پاک می‌شوند.

✉️ پیام خصوصی

جست‌وجوی نام کاربری و صندوق ورودی، با اتکا به پروفایل عمومی و RLS.

🌐 انجمن

ویرایش و حذف پیام توسط نویسنده؛ سرور همچنان مجوز نهایی را کنترل می‌کند.

🛡️ پنل مدیریت

نمایش پنل پس از بررسی نقش مدیر با RPC؛ عملیات حساس کاربر به Edge Function مدیریتی نیاز دارد.

برای فعال‌شدن پروفایل عمومی، صندوق ورودی، سیاست‌های RLS و مهاجرت Analytics، فایل SQL همراه باید در Supabase اجرا شود. کد HTML به‌تنهایی دیتابیس را تغییر نمی‌دهد.

🚀 PlayVault — اصلاحات Beta

این نسخه مسیر اتصال Community، DM، گزارش‌ها و آمار را یکپارچه‌تر می‌کند. قابلیت‌های سرور فقط پس از اجرای مهاجرت SQL و آزمون سیاست‌های RLS فعال می‌شوند.

🔐 حریم خصوصی پیام‌ها

پیام خصوصی باید فقط برای دو طرف گفتگو قابل خواندن باشد. برای جلوگیری از سوءاستفاده، محتوای DM به‌صورت خودکار و پنهانی پایش نمی‌شود.

🛡️ مدیریت با تأیید مدیر

عملیات حساس مانند محدودیت و بن نیازمند نقش مدیر تأییدشده سمت سرور است؛ کنترل مرورگر به‌تنهایی کافی نیست.

📊 آمار با کمینه‌سازی داده

طرح آمار بر شمارش بازدید صفحه و شناسه بازدیدکننده غیرمستقیم متکی است و IP را ذخیره نمی‌کند.
